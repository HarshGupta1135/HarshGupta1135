## 🚀 Featured Projects

### 🔗 [DevConnect: Developer Job Board with Smart Matching](https://github.com/HarshGupta1135/Dev-Connect-)
![Spring Boot](https://img.shields.io/badge/Spring%20Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![Redis](https://img.shields.io/badge/Redis-DC382D?style=flat-square&logo=redis&logoColor=white)
![JWT](https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white)

- 🔐 JWT authentication + role-based access control (**Developer / Recruiter / Admin**) with Spring Security and consistent 401/403/409 error handling
- 🧠 **Jaccard-similarity skill matching** scores jobs against developer profiles; dynamic filtering, pagination and sorting via JPA Specifications
- ⚡ **~14× faster repeat searches** (407 ms → 28 ms) with Redis caching and a custom Jackson-serializable DTO for Spring `Page` responses
- 🐳 Multi-stage Dockerfile + Docker Compose; deployed on Render, Vercel, Aiven MySQL and Upstash Redis with TLS
- 📦 React 19 + Vite frontend at a **128 kB gzipped core** with route-level code splitting and a Ctrl+K command palette

### 🧠 [AI Quiz Generator](https://github.com/HarshGupta1135/AI-Based-Quiz-Generation)
![Spring Boot](https://img.shields.io/badge/Spring%20Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![Ollama](https://img.shields.io/badge/Ollama%20(LLaMA%203)-000000?style=flat-square&logo=ollama&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![JWT](https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white)

- 📄 End-to-end pipeline that turns uploaded PDFs into multiple-choice quizzes with a **locally hosted LLaMA 3** via Ollama, with no external API dependency
- 🔍 PDF text extraction with Apache PDFBox + structured LLM prompting; **MD5-based duplicate detection** skips already-processed PDFs
- 🛡️ JWT auth with USER/ADMIN roles, plus an admin panel for managing users and quiz content
- 🎨 React frontend with PDF upload, interactive quiz-taking, live score tracking and light/dark mode
